# Tiar Property — Interactive Client Pitching & KPR Closing Portal

A specialized, high-converting interactive web application built for **Tiar Property (Surabaya - Sidoarjo)** to empower sales consultants and property strategists during live 1-on-1 client pitching, tablet presentations, and survey closing.

## 🧰 The 6 Client Pitching Tools
1. **Interactive KPR Simulator & Developer Subsidy Accumulator:** Live calculation of DP 0%, promo interest rates (3.4% - 4.5%), developer installment subsidy (Rp 1.4 Jt x 6-12 bln), free legal fees (BPHTB, AJB, BBN, Notary), and micro-installment daily breakdown (Rp 60.000/day).
2. **Interactive Scratchpad & Whiteboard Canvas:** Instant drawing board to sketch plot layouts, foundations, custom calculation notes, and export PNG directly to client's WhatsApp.
3. **Joint Income & Debt Burden Ratio (DBR 40%) Analyzer:** Real-time bank approval feasibility checker based on husband & wife combined income against ongoing installments.
4. **Rent vs Buy Financial Comparison Engine:** Visual financial proof contrasting 5-10 years of wasted rental money with 100% SHM property equity.
5. **Capital Gain & Surabaya-Sidoarjo Infrastructure Catalyst Calculator:** 3-5 year property appreciation model featuring RSUD Sedati 2027, Flyover Aloha, and MERR/OERR corridors.
6. **One-Click Official Proposal Slip Generator & WhatsApp Closing Engine:** Generates clean digital simulation slips and formatted human-grade WhatsApp chat drafts ready to send to prospective buyers.

## 🛠️ Tech Stack
- **Framework:** Next.js 15 (App Router, Static Export `output: 'export'`)
- **Styling:** Tailwind CSS v3.4 + OKLCH Colors + Rounded UI Primitives
- **Animations:** Framer Motion (physics-based spring transitions, smooth tab switching)
- **Icons:** Lucide React (`lucide-react`)
- **Canvas:** HTML5 2D Canvas with high-DPI retina support & PNG exporter
- **Confidentiality:** 100% internal compliance (Strict zero-mention of BLT).
